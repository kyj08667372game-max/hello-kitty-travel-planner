# 🎀 Hello Kitty Travel Planner
> **헬로키티와 함께하는 러블리 여행 준비물 체크 플래너**  
> Hello Kitty Travel Diary & Sanrio Cuties Checklist Web Application

![Hello Kitty Travel Diary Preview](assets/images/kitty_travel.jpg)

## 🌸 프로젝트 소개
헬로키티와 산리오 친구들(마이멜로디, 시나모롤, 쿠로미)이 여행을 준비하는 콘셉트의 귀엽고 실용적인 여행 준비물 체크 웹페이지입니다.  
타이핑할 필요 없이 **원클릭 스티커 선택(Pick)** 방식으로 빠르고 간편하게 짐을 꾸릴 수 있으며, 일본 겨울 여행 및 지역별 맞춤 추천 아이템을 스마트하게 제안합니다.

---

## ✨ 핵심 기능

1. **🎁 키티의 준비물 보물상자 (원클릭 스티커 선택)**
   - 복잡한 텍스트 입력 없이, 카테고리별 준비물 스티커를 톡 터치하여 담기
   - 이미 담긴 항목은 `✓` 표시와 함께 민트/그린 하이라이트로 실시간 상태 동기화
   - 목록에 없는 물품은 필요할 때만 인라인으로 직접 입력 가능

2. **❄️ 키티가 골라준 일본 겨울 여행 필수템 자동 추천**
   - 두꺼운 외투/패딩, 발열내의, 보습 크림, 립밤, 핫팩 등 겨울 필수템 제안
   - ⚡ 일본 전압(100V, 11자 A형 플러그) 변환 어댑터 안내 가이드 배너
   - 🔋 보조배터리 기내 반입(위탁 불가) 안전 수칙 안내
   - 추천 아이템 '준비물에 추가' 및 '전체 담기' 원클릭 지원

3. **🗺️ 여행 정보 맞춤 설정 연동**
   - 국가(일본, 한국, 대만, 기타), 계절(겨울, 봄, 여름, 가을), 지역(도쿄, 오사카, 교토, 삿포로/홋카이도, 후쿠오카), 여행 유형(일반, 온천, 스키/스노보드)
   - 삿포로 눈길 방수 방한화, 온천 여행 여분 속옷/수건, 스키장 고글/스키복 등 지역/유형별 특화 아이템 동적 반영

4. **🎀 6대 카테고리별 체크리스트**
   - 의류(핑크), 세면도구(민트), 전자기기(연보라), 서류·결제(크림), 의약품(피치), 기타(연노랑)
   - 카테고리별 완료 개수 / 전체 개수 실시간 뱃지
   - 체크박스 클릭 시 부드러운 애니메이션 및 취소선 피드백
   - 실수 방지 리본 팝업 삭제 모달 다이얼로그

5. **📊 실시간 진행률 & 축하 이벤트**
   - 진행률 퍼센트 & 리본 러너 프로그레스 바
   - 전체 / 완료 / 남은 준비물 3분할 카운터
   - 100% 완료 시 축하 메시지 (`"야호! 키티와 여행 준비 완료! 🎉"`) 및 파스텔 콘페티 이펙트

6. **💾 LocalStorage 자동 저장 & 완벽 복원**
   - 브라우저를 새로고침하거나 닫아도 체크 상태와 추가 항목 완벽 유지
   - 기본값으로 되돌릴 수 있는 `🔄 초기화` 기능 제공

7. **📱 반응형 웹 디자인 (Responsive Design)**
   - 모바일, 태블릿, PC 데스크톱 완벽 지원

## 🛠️ 기술 스택
- **Language**: HTML5, Vanilla CSS3, Modern JavaScript (ES6+)
- **Design System**: Sanrio Pastel Palette, Diary Card UI, Soft Shadows & Floating Animations
- **Typography**: Google Fonts (Jua, Gaegu, Nunito, Noto Sans KR)
- **Data Persistence**: Browser LocalStorage API

## 🚀 시작하기
별도의 빌드나 서버 설치 없이 웹 브라우저에서 `index.html`을 실행하면 바로 사용할 수 있습니다.

```bash
# 레포지토리 클론
git clone https://github.com/kyj08667372game-max/hello-kitty-travel-planner.git

# 폴더 이동
cd hello-kitty-travel-planner

# 브라우저에서 index.html 실행
```
